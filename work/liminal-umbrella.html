Northwestern MaDE Capstone

Liminal Umbrella

The problem

Closing and stowing a wet umbrella while getting into a car is messy, awkward, and hard to control.

The solution

A handle that closes the umbrella from the grip. Pull, ratchet, done, with no reach up the wet shaft.

01

Ideal user journey

Walk up, open the door, close the umbrella with one hand, and sit down dry.

02

Inside the prototype

01 / 05

Canopy

A custom pleated canopy that folds down cleanly and predictably.

02 / 05

Ratchet handle

A ratchet and pawl inside the handle, linked to the umbrella button, so closing can happen in small pulls.

03 / 05

Pull string

A braided cord transmits the force, and a 2:1 pulley halves the pull needed.

04 / 05

Pull handle

An adjustable locking tab secures the pull string at the handle.

05 / 05

Container

A slim container mounts to the handle to hold the wet canopy.
